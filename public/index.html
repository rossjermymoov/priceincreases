Railway Deployment Guide

When creating your Railway project, add:
  1. GitHub Repo: Connect `rossjermymoov/priceincreases`
  2. Database: Add a PostgreSQL service in Railway
  3. Environment: Set `DATABASE_URL` (auto-bound by Railway) and `BILLING_API_TOKEN`
Environment variables:
PORT=3000
DATABASE_URL=${{Postgres.DATABASE_URL}}
BILLING_API_BASE=https://production.billingapi.co.uk
BILLING_API_TOKEN=iiMcRFucDESz3pxU
SCHEDULE_DATE=2027-01-01T00:01:00Z
